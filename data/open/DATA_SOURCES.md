# Outside data sources

Every outside data source this project uses, as required by hard rule 3 in `CLAUDE.md`. Licenses were checked on each source's page on 2026-10-17. Our own synthetic data is in `data/generated/`, saved with its generation configs and seeds, and is not listed here.

The only outside data we use is Loghub, to make the environment's logs realistic. No outside dataset is used for training or for evaluation (see "Considered and not used" below).

| Source | Link | License | How we use it |
|---|---|---|---|
| Loghub | https://github.com/logpai/loghub | Loghub's own license: free for research or academic work; refer to the repository URL and cite the Loghub paper ([arXiv:2008.06448](https://arxiv.org/abs/2008.06448)). Not Apache-2.0. | The small `<System>_2k` samples are the basis of the canned `ops` logs (`gym_env/fixtures/logs.json`, built by `gym_env/fixtures/make_fixtures.py`). Healthy revisions get OpenStack API request lines; broken revisions get Zookeeper or Hadoop connection failures. We keep each line's level, component and content and replace its timestamp. Log lines derived from Loghub keep Loghub's license, including where they appear in tool results in our published trajectories. Files used, in `data/open/loghub/` with Loghub's `LICENSE` (its notice must go with every copy): `OpenStack_2k.log_structured.csv`, `Zookeeper_2k.log_structured.csv`, `Hadoop_2k.log_structured.csv`, all from commit [`dd61d09`](https://github.com/logpai/loghub/tree/dd61d0952749ee7963bde24220d1be5ede023033), downloaded 2026-10-17. |

## Considered and not used

| Source | License | Why not |
|---|---|---|
| [NeMo Gym Workplace Assistant](https://huggingface.co/datasets/nvidia/Nemotron-RL-agent-workplace_assistant) | CC-BY-4.0 | Planned as a check that fine-tuning didn't hurt general tool use (a seeded subset of the 545-row `validation` split; PLAN.md task 5.1, step 5), and cut for time on 2026-10-18 (cut list item 6): never downloaded or run. It appears to be WorkBench, which Lightning's model card lists in its post-training data, so Lightning scores on it wouldn't have been reported. |
| [When2Call](https://huggingface.co/datasets/nvidia/When2Call) (NVIDIA) | CC-BY-4.0 | Planned as a check that the student still knows when not to call a tool (a seeded subset of the `test` `mcq` split, never the `llm_judge` split, hard rule 6; PLAN.md task 5.1, step 5), and cut for time on 2026-10-18 (cut list item 6): never downloaded or run. |
| [Nemotron-Post-Training-Dataset-v1](https://huggingface.co/datasets/nvidia/Nemotron-Post-Training-Dataset-v1) (`tool_calling` split) | CC-BY-4.0 | Generated by DeepSeek-R1 and Qwen3-235B, both over 33B.
